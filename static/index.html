Tactile diagrams

Turn a textbook diagram into a Braille-labelled page for swell paper, embossing or 3D printing.

Page

Turn this off for swell paper: grey text would swell too.

Line work

Removes printed letters and specks. Dashed lines are kept. If some printed text is left, raise this, or choose "Erase area" above the sheet and drag a box over it.

Labels

Click a part of the diagram on the sheet: an arrow is placed on it, then type its name here. Each label becomes a Braille key letter on the diagram and a full Braille entry in the key. Drag a marker, or the ring at the end of an arrow, to move it. Arrow keys work too.

    Naming parts from the image uses a vision model. Pick a free provider and paste its key. The key stays in this running app's memory only.
